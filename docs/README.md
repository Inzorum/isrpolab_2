## Документация по геометрическим функциям

### Описание проекта
Библиотека geometric_lib предоставляет функции для вычисления:
- Площади геометрических фигур
- Периметра геометрических фигур

### Структура проекта
- `circle.py` - функции для работы с окружностью (площадь, периметр)
- `square.py` - функции для работы с квадратом (площадь, периметр)
- `triangle.py` - функции для работы с треугольником (площадь, периметр)

### Использование
```python
from circle import area, perimeter

radius = 5
print(f"Площадь круга: {area(radius)}")
print(f"Длина окружности: {perimeter(radius)}")
