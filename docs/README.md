# *Math formulas*
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

### Circle
Реализация:
```
import math;

def area(r):
    return math.pi * r * r


def perimeter(r):
    return 2 * math.pi * r

```
Общее описание функций:
- area(r):
  - *Принимает число r (радиус окуружности) на вход и возвращает площадь данной окуржности.*
  - *Параметры: r (int) - исходное число, радиус данной окружности.*
  - *Возвращаемое значение: area(r) (float) - площадь окружности (πr<sup>2</sup>).*
- perimeter(r):
  - *Принимает число r (радиус окружности) на вход и возвращает длину данной окружности.*
  - *Параметры: r (int) - исходное число, радиус данной окружности.*
  - *Возвращаемое значение: perimeter(r) (float) - длина окружности (2πr).*
Пример вызовов функций:
```
res = area(5)
print(res)
>> 78.5

c = perimeter(3)
print(c)
>> 18.84
```


### Square
Реализация:
```
def area(a):
    return a * a


def perimeter(a):
    return 4 * a

```
Общее описание функций:
- area(a):
  - *Принимает число a (сторона квадрата) на вход и возвращает площадь данного квадрата.*
  - *Параметры: a (int) - исходное число, сторона квадрата.*
  - *Возвращаемое значение: area(a) (int) - площадь квадрата (a<sup>2</sup>).*
- perimeter(a):
  - *Принимает число a (сторона квадрата) на вход и возвращает периметр данного квадрата.*
  - *Параметры: a (int) - исходное число, сторона квадрата.*
  - *Возвращаемое значение: perimeter(a) (int) - периметр квадрата (4 * a).*
Пример вызовов функций:
```
res = area(24)
print(res)
>> 576

res = perimeter(24)
print(res)
>> 96
```

### Rectangle 
Реализация:
```
def area(a, b):
    return a * b

def perimeter(a, b):
    return 2 * (a + b)
```
Общее описание функций:
- area(a, b):
  - *Принимает числа a, b (стороны прямоугольника) на вход и возвращает площадь данного прямоугольника.*
  - *Параметры:
            a (int) - первая сторона прямоугольника,
            b (int) - вторая сторона прямоугольника.*
  - *Возвращаемое значение: результат произведения a на b - area(a, b) (int) - площадь прямоугольника.*
- perimeter(a, b):
  - *Принимает числа a, b (стороны прямоугольника) на вход и возвращает периметр данного прямоугольника.*
  - *Параметры:
            a (int) - первая сторона прямоугольника,
            b (int) - вторая сторона прямоугольника.*
  - *Возвращаемое значение: удвоенная сумма сторон, что соответствует определению периметра - perimeter(a, b) (int)*
Пример вызовов функций:
```
res = area(3, 5)
print(res)
>> 15

res = peremeter(3, 5)
print(res)
>> 30
```

### Triangle
Реализация:
```
def area(a, h):
    return a * h / 2

def perimeter(a, b, c):
    return a + b + c
```
Общее описание функций:
- area(a, h):
  - *Принимает числа a, h (основание и высота треугольника) на вход и возвращает площадь данного треугольника.*
  - *Параметры:
            a (int) - основание треугольника,
            h (int) - высота треугольника, проведённая к основанию.*
  - *Возвращаемое значение: результат произведения a на h, делённый на 2 (int) - area(a, h) - площадь треугольника.*
- perimeter(a, b, c):
  - *Принимает числа a, b, c (стороны треугольника) на вход и возвращает периметр данного треугольника.*
  - *Параметры:
            a (int) - первая сторона треугольника,
            b (int) - вторая сторона треугольника,
            c (int) - третья сторона треугольника.*
  - *Возвращаемое значение: сумма всех трёх значений сторон (int) - perimeter(a, b, c) - периметр треугольника*
Пример вызовов функций:
```
res = area(4, 3)
print(res)
>> 6

res = perimeter(3, 3, 4)
print(res)
>> 10
```
