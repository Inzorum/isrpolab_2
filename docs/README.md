# ***Geometric Lib***
## **Geometric Lib** - это библиотека на Python для вычисления площадей и периметров геометрических фигрул (квадрат, прямоугольник, треугольник и круг)

## Сейчас я расскажу про описание каждой функции с примерами вызова
### _square.py_
#### area(a)
Программа вычесляет **площадь квадрата**, функция *принимает его сторону*
- Пример использования: area(5) -> 25

#### perimeter(a)
Программа вычесляет **периметр квадрата**, функция *принимает его сторону*
- Пример использования: perimeter(5) -> 20

### _rectangle.py_
#### area(a,b)
Программа вычесляет **площадь прямоугольника**, функция *принимает две его разные стороны*
- Пример использования: area(4,7) -> 28

#### perimeter(a,b)
Программа вычесляет **периметр прямоугольника**, функция *принимает две его разные стороны*
- Пример использования: perimeter(4,7) -> 22

### _triangle.py_
#### area(a,h)
Программа вычесляет **площадь треугольника**, функция *принимает его основание и высоту*
- Пример использования: area(6,9) -> 27

#### perimeter(a,b,c)
Программа вычесляет **периметр треугольника**, функция *принимает три его стороны*
- Пример использования: perimeter(6,7,8) -> 21

### _circle.py_
#### area(r)
Программа вычесляет **площадь круга**, функция *принимает его радиус*
- Пример использования: area(5) -> 78.53981633974483

#### perimeter(r)
Программа вычесляет **периметр круга**, функция *принимает его радиус*
- Пример использования: perimeter(5) -> 31.41592653589793
