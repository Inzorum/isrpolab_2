# Geometric Library

A Python library for calculating area and perimeter of geometric shapes.

# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = sqrt(p * (p-a) * (p-b) * (p-c)), where p is semiperimeter

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c
