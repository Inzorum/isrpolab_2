# How to use

The library contains two figure calculators:

1. Run `python circle.py` — for a circle
2. Run `python square.py` — for a square
3. Enter the size that the program asks for
4. The program prints the area and the perimeter

# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
