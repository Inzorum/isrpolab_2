# Лабораторная работа №2
Библиотека geometric_lib позволяет вычислять площади и периметры таких геометрических фигур как квадрат, прямоугольник и треугольник
## 1. rectangle.py

 > area(a,b)

- Принимает значения сторон прямоугольника
* Возвращает значение площади прямоугольника с этими сторонами
+ Пример вызова функции:
```
import rectangle
print(rectangle.area(4,6))
#Программа выведет 24
```
 > perimeter(a,b)
- Принимает значения сторон прямоугольника
* Возвращает значение периметра прямоугольника с этими сторонами
+ Пример вызова функции:
```
import rectangle
print(rectangle.perimeter(2,3))
#Программа выведет 10
```
## 2. circle.py

 > area(r)

- Принимает значение радиуса окружности
* Возвращает значение площади окружности с этим радиусом
+ Пример вызова функции:

```
import circle
print(circle.area(5))
#Программа выведет ~78.5
```

 > perimeter(r)

 - Принимает значение радиуса окружности
 * Возвращает значение длины окружности с этим радиусом
 + Пример вызова функции:

```
import circle
print(circle.area(5))
#Программа выведет ~31.4
```

## 3. square.py

 > perimeter(a)

- Программа принимает значение стороны квадрата
* Возвращает значение периметра квадрата с данной стороной
+ Пример вызова функции:
