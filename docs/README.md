# Документация Geomeric Lib

## Общее описание решение
Geomeric Lib - это библиотека для вычисления площадей и периметров геометрических фигур.

## Описание функций 

### circle.py

#### area(r)
Программа вычисляет площадь круга. 
- Пример вызова: area(5) -> 78.54

#### perimeter(r)
Программа вычисляет периметр круга.
- Пример вызова: area(5) -> 31.42

### square.py

#### area(a)
Программа вычисляет площадь квадрата.
- Пример вызова: area(4) -> 16

#### perimeter(a)
Программа вычисляет периметр квадрата.
- Пример вызова: perimeter(4) -> 16

### rectangle.py

#### area(a,b)
Программа вычисляет площадь прямоугольника. 
- Пример вызова: area(5, 3) -> 15

#### perimeter(a,b)
Программа вычисляет периметр прямоугольника.
- Пример вызова: perimeter(5,3) -> 16

### triangle.py

#### area(a,h)
Программа вычисляет площадь треугольника. 
- Пример вызова: area(6,4) -> 12

#### perimeter(a,b,c)
Программа вычисляет периметр треугольника.
- Пример вызова: perimeter(1,2,3) -> 6

## План тестирования

### Цели и задачи тестирования
- Проверить корректность вычисления площадей и периметров геометрических фигур
- Убедиться в обработке некорректных входных данных

### Описание тестируемого продукта
geometric_lib:
- circle - вычисление площади и периметра круга
- rectangle - вычисление площади и периметра прямоугольника  
- square - вычисление площади и периметра квадрата
- triangle -  вычисление площади и периметра треугольника

### Область тестирования
- Функции area() и perimeter() всех модулей
- Обработка валидных и невалидных входных данных
- Проверка типов данных

### Стратегия тестирования
- Unit-тестирование с использованием unittest

### Критерии приемки
- Все unit-тесты проходят успешно
- Покрытие кода тестами >90%
