# geometric_lib

Учебная библиотека на Python для вычисления площади и периметра простых
геометрических фигур: круга и квадрата.

## Структура проекта

| Файл             | Назначение                                       |
|------------------|--------------------------------------------------|
| `circle.py`      | функции `area(r)` и `perimeter(r)` для круга     |
| `square.py`      | функции `area(a)` и `perimeter(a)` для квадрата  |
| `docs/README.md` | документация проекта                             |

## Формулы

### Площадь
- Круг: S = πR²
- Прямоугольник: S = ab
- Квадрат: S = a²

### Периметр
- Круг: P = 2πR
- Прямоугольник: P = 2a + 2b
- Квадрат: P = 4a

## Описание функций

### `circle.py`

| Функция        | Параметр          | Возвращает                 |
|----------------|-------------------|----------------------------|
| `area(r)`      | `r` — радиус круга | площадь круга `π·r²`       |
| `perimeter(r)` | `r` — радиус круга | длину окружности `2·π·r`   |

### `square.py`

| Функция        | Параметр            | Возвращает                |
|----------------|---------------------|---------------------------|
| `area(a)`      | `a` — длина стороны | площадь квадрата `a²`     |
| `perimeter(a)` | `a` — длина стороны | периметр квадрата `4·a`   |

## Пример использования

Запускать из корня репозитория (Python 3):

```python
import circle
import square

print(circle.area(1))        # 3.141592653589793
print(circle.perimeter(1))   # 6.283185307179586
print(square.area(4))        # 16
print(square.perimeter(4))   # 16
```

## Ограничения

- Функции не проверяют входные данные: для отрицательного радиуса или
  стороны возвращается формальный результат без сообщения об ошибке.
- Формулы для прямоугольника приведены справочно: модуля `rectangle.py`
  в ветке `main` пока нет.
