# Документация Geometric Lib

## Общее описание решения
Geometric Lib - библиотека, позволяющаяя вычислить различные значения для геометрических фигур, такие, как площадь периметр и прочие.

## Описание функций

### circle.py

#### area(r)
Программа вычисляет площадь круга.
- Пример вызова: area(4) -> 50.24

#### perimetr(r)
Программа вычисляет периметр круга.
- Пример вызова: perimetr(4) -> 25.12

### square.py

#### area(r)
Программа вычисляет площадь квадрата.
- Пример вызова: area(4) -> 16

#### perimetr(r)
Программа вычисляет периметр квадрата.
- Пример вызова: perimetr(4) -> 16

### rectangle.py

#### area(r)
Программа вычисляет площадь прямоугольника.
- Пример вызова: area(5, 2) -> 10

#### perimetr(r)
Программа вычисляет периметр прямоугольника.
- Пример вызова: perimetr(5, 2) -> 14

### triangle.py

#### area(r)
Программа вычисляет площадь треугольника.
- Пример вызова: area(5, 4) -> 10

#### perimetr(r)
Программа вычисляет периметр треугольника.
- Пример вызова: perimetr(2, 3, 4) -> 9
