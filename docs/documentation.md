# geometric_lib 

## Общее описание репозитория
Содержит 4 файла, каждый из которых выполняет расчет площади и периметра определенной геометрической фигуры
1. circle.py :
    
    Содержит две функции, вычисляющие площадь и периметр окружности
2. rectangle.py :
    
    Содержит две функции, вычисляющие площадь и периметр прямоугольника
3. square.py :
    
    Содержит две функции, вычисляющие площадь и периметр квадрата
4. triangle.py :
    
    Содержит две функции, вычисляющие площадь и периметр треугольника
## Описание функций с примерами их вызова
1. сircle.py:
    Внутри две функции:

         def area(r) - получает на вход радиус окружности, после конца работы передает ее площадь. 
         
         Пример:
         area(100) - возвращат 31415.926535897932
         
         def perimetr(r) - получает на вход радиус окружности, после конца работы передает ее периметр. 
         
         Пример:
         perimetr(100)  - возвращает 628.3185307179587
2. rectangle.py :
    
    Внутри две функции:
         
         def area(a, b) - получает на вход длины первой и второй сторон прямоугольника, после конца работы передает его площадь. 
         
         Пример:
         area(100, 100) - возвращат 10000
         
         def perimetr(a, b) - получает на вход длины первой и второй сторон прямоугольника, после конца работы передает его периметр. 
         
         Пример:
         perimetr(100, 100)  - возвращает 400
3. square.py :
    
    Внутри две функции:
         
         def area(a) - получает на вход длину первой стороны квадрата, после конца работы передает его площадь. 
         
         Пример:
         area(100) - возвращат 10000
         
         def perimetr(a, b) - получает на вход длину первой стороны квадрата, после конца работы передает его периметр.  
         
         Пример:
         perimetr(100)  - возвращает 400
4. triangle.py :
    
    Внутри две функции:
         
         def area(a, h) - получает на вход длины основания и построенной к этому основанию высоты треугольника, после конца работы передает его площадь. 
         
         Пример:
         area(100, 100) - возвращат 5000
         
         def perimetr(a, b, c) - получает на вход длины всех сторон треугольника, после конца работы передает его периметр.  
         
         Пример:
         perimetr(100, 100, 100)  - возвращает 300
